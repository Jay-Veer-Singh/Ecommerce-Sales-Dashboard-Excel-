# 🛒 Ecommerce Sales Dashboard (Excel)

## 📊 Overview
This project is an interactive Ecommerce Sales Dashboard built in Microsoft Excel.  
It provides insights into customer behavior, sales performance, and operational efficiency.

---

## 🎯 Key Business Questions Answered
- How are sales performing over the last 13 weeks?
- How do customers prefer to buy? (App, Website, Instagram, etc.)
- How many items do customers purchase per order?
- Which products are most popular?
- How long does shipping take?
- How are customer ratings distributed?

---

## 📌 Key Metrics (KPIs)
- Total Orders: 2,400  
- Total Quantity Sold: 11,997  
- Total Revenue: $649K  
- Average Rating: 4.0 ⭐  
- Average Delivery Time: 2.3 Days  

---

## 📈 Dashboard Features
- 📉 Weekly trend analysis (Quantity & Revenue)
- 📊 Order quantity distribution
- 📦 Product popularity breakdown by gender
- 🚚 Shipping time distribution
- ⭐ Ratings analysis
- 🎯 Interactive filters (Order Mode, Gender)

---

## 🛠 Tools & Skills Used
- Microsoft Excel  
- Pivot Tables  
- Pivot Charts  
- Data Cleaning & Transformation  
- Conditional Formatting  
- Dashboard Design  

---

## 💡 Insights
- Most customers prefer purchasing via App and Website  
- Majority of orders contain 2–3 items  
- T-Shirts and Sneakers are top-selling products  
- Most deliveries are completed within 2–3 days  
- Customer ratings are generally positive (4+)
